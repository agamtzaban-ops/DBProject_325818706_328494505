# HotelMaster - Employee & Shift Management System

## Team Members
* Agam Tzaban
* Osnat Zimmerman

## Project Overview
The "HotelMaster" system is designed to manage hotel employees and their weekly shifts. The system handles employee profiles, shift scheduling across different hotel departments, and tracks employee attendance (Clock In / Clock Out).
